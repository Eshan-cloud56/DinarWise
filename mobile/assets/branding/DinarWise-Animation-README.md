# DinarWise Splash Animation

## Sequence

1. A sea-green hand enters from the lower-left.
2. The hand flicks an aged gold dinar coin upward.
3. The coin flips through two rotations, showing its engraved face.
4. The hand exits while the coin settles with a small bounce.
5. `DinarWise` and `EXPENSE MANAGEMENT` reveal beneath the coin.

## Mobile implementation

Use the MP4 as the most compatible splash video. Keep the native operating-system launch screen static, then play this animation immediately inside the app while initial local data loads. The SVG is useful for web previews and platforms that support animated SVG.
